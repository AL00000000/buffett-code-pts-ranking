# PTS株価ランキング (値上がり・値下がり 各上位30)

[バフェット・コード PTSランキング](https://www.buffett-code.com/pts) の値上がり・値下がりランキング上位30銘柄を毎営業日深夜に取得したデータです。

**📊 閲覧用サイト: https://al00000000.github.io/buffett-code-pts-ranking/**
(値上がり/値下がり/翌日最高値との差 のタブ切替・日付切替・列ソート・銘柄検索ができます)

## タブ

| タブ | 内容 |
| --- | --- |
| 値上がり / 値下がり | 深夜0時時点のPTSランキング上位30銘柄 |
| 翌日最高値との差 | 各銘柄のPTS価格と、翌営業日の場中4本値との差 |
| 翌日最高値との差(貸借のみ) | 上と同じ内容を貸借銘柄だけに絞ったもの |

### 「翌日最高値との差」について

夜間PTSでは空売りができないため需給が買いに偏り、翌日の場中より高くなりやすいのではないか、という仮説の検証用データです。
前営業日に両建て(現物買い+信用売り)を作っておき、夜間PTSで現物だけを売れば、実質的にPTS価格でのショートになります。

各「差」は **PTS価格 − 翌日の値** で、プラスならPTSのほうが高かったことを意味します。
とくに**高値との差がプラス**なら、翌日は一日を通じてPTS価格を一度も上回らなかった、つまりどのタイミングで買い戻しても利益になったケースです。

制度信用で確実に空売りできるのは**貸借銘柄**だけなので、実際に組めるのは貸借銘柄に絞ったタブのほうです。
ただしデータとしては信用銘柄・現物銘柄も含めてすべて保存しており、両方を載せたタブも残しています。

## データ

- [docs/data/](docs/data/) … 閲覧用サイトが読み込む日次JSON
- [docs/data/nextday.json](docs/data/nextday.json) … 「翌日最高値との差」タブ用データ(全日付ぶん)
- [output/](output/) … 日次のランキングCSV (`ranking_YYYY-MM-DD.csv`, UTF-8)
  - 区分(値上がり/値下がり) / 順位 / 順位変動 / 前回順位 / コード / 銘柄名 / 市場 / 現在値 / 更新時刻 / 前日比 / 前日比% / 出来高 / 売買代金(推計) / 時価総額 / PER / PBR
- [history/](history/) … 比較計算用の生データ (JSON)

順位変動の表記: `↑n`(n位上昇) / `↓n`(n位下降) / `→`(変わらず) / `NEW`(前回圏外から登場)

## 取得スクリプト

いずれもPython標準ライブラリのみで動作します。

```
py fetch_ranking.py    # 深夜0時: PTSランキングを取得
py fetch_nextday.py    # 平日16時: 翌営業日の場中4本値・信用区分を取得
```

`fetch_nextday.py` は取得済みの日足と信用区分を `nextday_cache.json` に貯めるため、
2回目以降は新しい銘柄ぶんしか取りにいきません(このキャッシュはコミットしません)。

## 注意

- データの取得元は buffett-code.com(PTS)と [株探](https://kabutan.jp/)(翌営業日の4本値・信用区分)です。データの正確性は保証しません。投資判断は自己責任でお願いします。
- 市場休場日は更新されません。
- 翌営業日がまだ到来していない日付は「翌日最高値との差」の集計に含まれません。
